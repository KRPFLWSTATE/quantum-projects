# Limitations and contributions

This repository is a bounded software-and-data artifact. It does not establish quantum advantage, organisational effectiveness, or journal acceptance.

Limitations include: six synthetic six-variable fixtures; six clustered hardware blocks in 18 minutes; Open Plan `ibm_fez` only; shared samples across P0–P3; prefix analyses that do not save the already-paid shot budget; no specification-change event in the hardware jobs themselves; P2’s payload-equality contract rather than a pure version-string gate; historical `parameter_source=frozen_p1` labels on some p=2 simulation-prefix rows; incomplete per-job Python lockfiles.

Prior-art and contribution claims belong to the manuscript, which this task does not modify. Historical editorial files that said “hardware later” or “jobs = 0” are preserved under `archive/historical-public-docs/` and must not be presented as current.
